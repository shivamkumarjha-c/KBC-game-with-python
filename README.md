# KBC Game with Python

A command-line quiz game inspired by *Kaun Banega Crorepati*. Answer 10 questions and build your prize total as you play.

## How to play

Run the game with Python 3:

```bash
python kbc_game.py
```

Type your answer when prompted. Enter `quit` whenever you want to stop and take the prize you have earned so far.

- A correct answer moves you to the next round.
- If you miss a question in rounds 1–6, you keep the prize from your last correct answer.
- If you continue into rounds 7–10 and answer incorrectly, you leave with nothing.
